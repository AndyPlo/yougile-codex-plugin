# YouGile для Codex

Локальный плагин для подключения к официальному удалённому MCP YouGile.
Локальный MCP-сервер, npm, API-ключ и `.env` не требуются.
Адрес сервера задан в `plugins/yougile/mcp.json`; это конфигурация, которую читает Codex.
Авторизацией OAuth и хранением полученных учётных данных занимается клиент Codex.

## Установка

Зарегистрируйте локальный каталог плагинов:

```sh
codex plugin marketplace add /Users/andy_plo/dev/yougile-plugin
```

Затем в Codex откройте Plugins, найдите YouGile в каталоге YouGile Local и установите.
При запросе подключения пройдите авторизацию YouGile в браузере.
В профиле YouGile должна быть включена интеграция с ИИ-ассистентами MCP;
для входа используйте https://ru.yougile.com/team/.
Выберите доступ только на чтение, чтобы получать задачи для локальной обработки.
Надпись Read в манифесте — описание возможностей, а не ограничение прав:
фактические права задаются при разрешении доступа в YouGile.

После установки начните новый чат, проверьте наличие инструментов YouGile
и запросите список доступных проектов или задач без изменений данных.
OAuth и получение задач необходимо проверить на вашей учётной записи:
наличие адреса в конфигурации само по себе не подтверждает успешное подключение.

## Включение и отключение

Включайте и отключайте плагин в разделе Plugins клиента Codex.
После изменения начните новый чат, чтобы проверить актуальный набор инструментов.
Отключение плагина не удаляет историю чатов и не отзывает выданный доступ OAuth.
При необходимости отзовите разрешение отдельно в YouGile.
Не добавляйте этот же сервер отдельно в глобальный MCP-конфиг: это создаст
второе подключение, которое не будет зависеть от переключателя плагина.

## Структура

- `.agents/plugins/marketplace.json` — локальный каталог для установки.
- `plugins/yougile/plugin.json` — переносимый манифест плагина.
- `plugins/yougile/.codex-plugin/plugin.json` — слой совместимости Codex
  с явной ссылкой на `./mcp.json`, по проверенной структуре Telegram-плагина.
- `plugins/yougile/mcp.json` — HTTP-сервер; OAuth используется клиентом по умолчанию.

Плагин не содержит исполняемого кода, зависимостей или секретов.
Codex устанавливает копию в собственный кэш; после изменения исходных файлов
обновите или переустановите плагин, чтобы применить изменения.

## Раздельная диагностика

1. Проверка упаковки: Codex должен обнаружить YouGile в локальном каталоге.
2. Проверка сервера: неавторизованный POST initialize должен вернуть OAuth
   challenge (HTTP 401 с WWW-Authenticate). GET может вернуть HTTP 405.
3. Проверка авторизации: подключение в клиенте и согласие в браузере.
4. Проверка работы: чтение списка задач через доступные инструменты MCP.

Первые два шага не подтверждают третий и четвёртый: так можно отделить ошибку
упаковки плагина от ошибки авторизации или поведения удалённого сервера.

## Совместимость с Codex 0.163.0

В `mcp.json` намеренно отсутствует `extensions.com.openai.auth`: в установленной
версии этот блок приводил к пропуску сервера при загрузке плагина. Для HTTP
OAuth используется по умолчанию. После установки сервер должен появиться
в `codex mcp list`; для явного запуска входа выполните `codex mcp login yougile`.
