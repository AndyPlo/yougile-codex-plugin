# v0.1.1 — YouGile Codex Plugin

An unofficial Codex plugin for the official YouGile MCP server. Connect your own
YouGile account through browser authorization and read projects and tasks in Codex.
No local MCP server, Node.js, npm, API key, or `.env` file is required.

## What changed

- English setup instructions for installation from GitHub or any local clone.
- Explicit read-only OAuth login and guidance on permissions and revocation.
- Troubleshooting and update instructions, including Codex cache behavior.
- Public repository metadata, an MIT license, and ignore rules for local files.
- IDE configuration removed from tracking.
- Optional package validation and isolated installation checks using the Codex CLI.

The plugin identifier remains `yougile@yougile-local`.

## Install this version

After the `v0.1.1` tag has been published, new users can install this exact version:

```sh
codex plugin marketplace add AndyPlo/yougile-codex-plugin --ref v0.1.1
codex plugin add yougile@yougile-local
codex mcp login yougile --scopes read
```

Enable MCP access in your YouGile profile first, then approve read-only access
when prompted. Start a new Codex chat after installation and login.
A pinned tag stays on this version; it does not track later releases.

For prerequisites, the desktop installation flow, and updating an existing
installation, see the [README](https://github.com/AndyPlo/yougile-codex-plugin/blob/v0.1.1/README.md).

## Validation and compatibility

Verified on macOS with Codex CLI 0.163.0:

- Installation of version 0.1.1 directly from the GitHub repository in an isolated
  temporary Codex home, before tagging the release.
- Correct HTTP MCP discovery and loading from the installed cache after the
  marketplace source was moved away.
- Paths containing spaces and removal of the temporary installation afterward.

OAuth authorization and reading data in a Codex chat were verified separately.
The isolated installation check did not log in or access account data.
Windows, Linux, other MCP clients, self-hosted YouGile, and write operations
have not been verified. This project is not affiliated with YouGile or OpenAI.
